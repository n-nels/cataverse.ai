# `src/analysis/` Overview

High-level guide to the analysis modules. This file is intentionally brief and
focuses on module responsibilities rather than algorithm details.

## Module Responsibilities

- `main.py`: Orchestrates the analysis pipeline for a spectrum file, coordinating
  spectral fitting, kinetics, and peak height extraction in the legacy order.
- `spectral_fitting.py`: Performs Voigt-profile spectral fitting (`least_squares`)
  and produces peak parameters used for downstream processing. Spectra with no
  peak in the baseline-corrected ROI are not fitted (area 0).
- `baseline.py`: The anchored two-segment baseline (`voigt_fit.baseline_recipe`),
  a port of the offline `BaselineVariant()` default.
- `classification.py`: The causal Peak_1988 nucleation detector
  (`kinetics_classification`), a port of `src/utils/kinetics/classification.py`.
- `segments.py`: Segment-wise kinetic fits and features (`kinetics_segments`), a
  port of `src/utils/kinetics/segments.py`. Rerun on the whole trajectory after
  every spectrum; provisional until the run ends.
- `kinetics_fitting.py`: Kinetic models (pfo, secondary_pfo, exp_decay), the
  peak-group sums and the classification merge.
- `peak_heights.py`: Computes peak heights and summary metrics for reporting.
- `output.py`: Writes analysis outputs (CSV artifacts, plots where applicable)
  with legacy filenames and schemas.
- `io.py`: Handles loading spectrum data, validating input structure, and
  normalizing data representations before fitting.
- `integrate_ir_iso_xchg.py`: Specialized isotopic exchange processing utilities
  retained for compatibility with legacy workflows.

## Notes

- Configuration is driven by `config/analysis.yaml` via `src.core.config`.
- Legacy output filenames are preserved. Since 2026-10-09 (docs/spec-live-migration.md)
  `*_CarbonylPeakArea.csv` carries `classification`, `growth_onset_s` and
  `latch_time_s` on `cluster_sum` rows instead of per-row pfo columns, and
  `*_CarbonylKineticParams.csv` / `*_CarbonylKineticFeatures.csv` are new.
